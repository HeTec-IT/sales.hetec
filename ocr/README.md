# PS Smart Scan 2.0 Beta

Experimental branch; do not merge or deploy before device testing. Offer photos are processed on the device only. The frontend patch removes the offer cloud call; handwriting and the existing parser/multi-page merge remain. PP-OCRv6 tiny in a dedicated single-thread WASM worker; Tesseract fallback and targeted labelled total area. Static SDK/model assets are built in CI and served by the PWA, not used as a cloud inference service. The existing camera and preprocessing remain; no new perspective/multi-frame feature yet. Generated OCR assets use a versioned service worker cache (storage may be evicted). First load needs internet. Target 12-second shared scan budget, 3–5 seconds warm, not measured. The cold model initialization may take longer and falls back to Tesseract during a scan.

Run node scripts/patch-smart-scan.cjs, node --test tests/ocr/*.test.mjs scripts/test-smart-scan.mjs, then cd ocr && npm install && npm run build. CI applies and commits the large HTML and bundle only after tests and build pass. Test actual photos on S9 FE and iPad, repeated tariff names, multipage continuation, prices/rabates, glare, aborts and airplane mode. No production deployment. The old cloud-mock browser test is not the new acceptance test. No claim of device compatibility until measured. Existing manual correction remains available.
